# 应用管理 · 交互预览

直接双击 `index.html` 用浏览器打开即可，不需要 Web 服务器，也不会向路由器发送任何请求。也可以直接打开 `dist/appmanager-preview.html`（把 CSS/JS 内联进去的单文件版）。

微信策略已经合并到应用管理里的“微信视频号”应用：保留聊天/支付/朋友圈/视频通话，封视频号/公众号/小程序。单独的 `wechat.html` 保留为历史实验页，不再出现在完整预览里。

完整预览就是应用管理页本身：打开 `index.html`，或单文件版 `dist/complete-preview.html`。

这个页面把正式插件 `luci-app-appmanager` 的交互和规则生成逻辑做成了浏览器模型：

- 勾选/取消应用，右侧规则实时变化；
- 关闭“管控已开启”，9/10 条规则会变成注释；
- 添加设备后填 IP，可以看到多设备合并成 `OR,((SRC-IP...),(SRC-IP...))`；
- “添加自定义应用”支持域名和 `ip:1.2.3.0/24`；
- “命中测试”用 fake-ip 流程模拟 `REJECT` / `ALLOW`；
- 规则输出区分“自定义规则文件”和“运行配置 次元.yaml”；
- 复制/下载只下载浏览器里生成的文本，不写路由器。

页面里的 `10.10.10.27` 是演示数据。正式插件读取的是 `/etc/appmanager/config`，并通过 `/usr/sbin/appmanager` 写入 OpenClash 配置。
